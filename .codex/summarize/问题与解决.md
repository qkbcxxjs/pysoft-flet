# 问题与解决

## 2026-08-16 17:49

### 问题

1. PyInstaller 打包为单文件后，左上角窗体图标失效。`main.py` 的 `Services.get_asset_path()`（第 36-37 行）通过 `get_app_dir()` 计算资源路径；冻结运行时 `get_app_dir()` 返回 `sys.executable` 所在目录（第 30-33 行）。但 `.spec` 将 `assets` 打入单文件（第 4 行），运行时实际解包到 `sys._MEIPASS/assets`，因此 `page.window.icon`（`main.py` 第 623 行）得到不存在的路径。`.spec` 的 `EXE(icon=...)`（第 42 行）只设置 EXE 文件图标，不会替代 Flet 运行时窗口图标。

2. `assets` 内的 SVG 等文件读取失败。原因与图标一致：`ft.run(..., assets_dir=str(Services.get_asset_path(\"\").resolve()))`（`main.py` 第 1919 行）把 Flet 的资源根目录指向 EXE 同级的不存在目录。使用相对 `src` 的导航图标和顶部 Logo（第 637、649、699、1483 行）因此无法由 Flet 的资源服务定位。

3. 顶部内容略有遮挡。窗口初始化（第 617-625 行）将 `page.padding` 设为 `0`，根 `Row`（第 1910 行）直接从页面顶部开始铺满；没有声明内容区与系统标题栏/安全区的关系。在 Windows 桌面端的标题栏绘制或 DPI 缩放下，首行内容会贴边并可能进入系统侵入区，产生轻微遮挡。

### 解决方案

1. 修改 `main.py` 的 `Services` 类，在 `get_app_dir()` 后新增 `get_bundle_dir()`：冻结运行时返回 `Path(sys._MEIPASS)`，开发运行时返回 `Path(__file__).resolve().parent`。将第 36-37 行的 `get_asset_path()` 改为基于 `get_bundle_dir() / \"assets\" / filename`。

   修改方案：

   ```python
   @staticmethod
   def get_bundle_dir() -> Path:
       if getattr(sys, "frozen", False):
           return Path(getattr(sys, "_MEIPASS"))
       return Path(__file__).resolve().parent

   @staticmethod
   def get_asset_path(filename: str) -> Path:
       return Services.get_bundle_dir() / "assets" / filename
   ```

   修改理由：PyInstaller 单文件模式会在 `_MEIPASS` 解包 `datas`，因此窗口图标（第 623 行）和 `ft.run` 的 `assets_dir`（第 1919 行）能够命中真实的只读资源目录。不要改变 `get_app_dir()`：它仍应以 EXE 同级目录为根，供数据库、附件和临时文件持久化，避免把用户数据写入会被删除的 `_MEIPASS` 临时目录。

2. 保留 `.spec` 第 4 行 `datas = [('assets', 'assets')]` 和第 42 行 `icon=['assets/soft_logo.ico']`，无需把图标重复复制到 EXE 同级目录。重新构建时确认该 `.spec` 被使用。

   修改理由：前者负责把 Flet 运行时页面资源打入包内，后者负责 Windows 资源管理器/任务栏的 EXE 图标；修复后的 `page.window.icon` 会从同一包内资源根加载运行时窗体图标，三者职责明确。

3. 修改 `main.py` 的 `QKBCASApp.get_setup_window()`，在设置尺寸后显式增加：

   ```python
   self.page.window.title_bar_hidden = False
   ```

   再修改 `QKBCASApp.get_start()` 第 1910 行：先将现有 `ft.Row(...)` 保存为 `root`，再添加安全区包装：

   ```python
   root = ft.Row(
       expand=True,
       spacing=0,
       vertical_alignment=ft.CrossAxisAlignment.STRETCH,
       controls=[self.nav_panel, self.content_panel],
   )
   self.page.add(ft.SafeArea(
       expand=True,
       minimum_padding=ft.Padding(0, 8, 0, 0),
       content=root,
   ))
   ```

   修改理由：显式保留原生标题栏可避免内容布局与标题栏覆盖模式混用；`SafeArea` 会避开操作系统侵入区，`8px` 最小上边距同时消除高 DPI 下的贴边视觉遮挡。根布局仍 `expand=True`，不会破坏左右面板的高度填充和现有自适应宽度计算。

4. 完成后使用单文件 EXE 验证，而非仅以 `python main.py` 验证：检查标题栏左上角和任务栏图标、所有导航 SVG/顶部 Logo、首屏顶部边缘、以及 EXE 同级 `qkbc_merchant_data` 的数据库及附件读写。开发态可正常运行不代表 `_MEIPASS` 路径逻辑已正确。
